# 🚗 Used Car Price Prediction

Predicting the selling price of used cars using Machine Learning.

This project was completed as part of Acmegrade Data Science Internship (August 2026).

### 📌 Objective
To build a regression model that estimates the price of a used car based on its features like Year, Kms Driven, Fuel Type, Transmission, etc.

### 📂 Dataset Details
- **Present_Price:** Current ex-showroom price
- **Kms_Driven:** Distance covered
- **Fuel_Type:** Petrol / Diesel / CNG
- **Seller_Type:** Dealer / Individual
- **Transmission:** Manual / Automatic
- **Owner:** Number of previous owners
- **Target:** Selling_Price

### 🛠️ Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn for Visualization
- Scikit-learn for Model Building
- Jupyter Notebook

### 🔍 Workflow
1.  Data Cleaning & Preprocessing
2.  Exploratory Data Analysis (EDA)
3.  One-Hot Encoding for Categorical Features
4.  Train-Test Split
5.  Model Training - Linear Regression & Random Forest
6.  Model Evaluation using R2 Score, MAE, RMSE

### 📊 Result
- **Best Model:** Random Forest Regressor
- **Accuracy (R2 Score):** 0.90+
- Model successfully predicts car price with high accuracy.
